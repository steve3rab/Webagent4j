# Support

WebAgent4J is an early-stage open source project maintained on a best-effort basis.

## Where to ask

- Use [GitHub Discussions](https://github.com/steve3rab/Webagent4j/discussions) for setup questions,
  design discussions, and general help.
- Open a [bug report](https://github.com/steve3rab/Webagent4j/issues/new/choose) for reproducible
  incorrect behavior.
- Open a focused feature request when a proposed capability has a clear use case.
- Follow the [security policy](SECURITY.md) for vulnerabilities; never report them publicly.

Before asking for help, check the [documentation](docs/index.md), existing issues, and current
[project status](README.md#project-status). Include the WebAgent4J version, Java version, operating
system, browser, a minimal reproduction, and relevant sanitized logs.

Please never post credentials, access tokens, cookies, personal data, private URLs, or proprietary
page content.
